## 0. 产品概述

**产品名**：CineAI Studio — AI 短剧创作工作台

**一句话定位**：输入一句话创意，AI 自动生成分镜剧本 → 逐镜生成画面 → 生成视频片段 → 3D 导演台精修走位机位 → 一键合成导出短片。

**目标用户**：短视频创作者、短剧编剧、MCN 团队。

**设计基调**：
- 关键词：**电影感、专业创作工具、暗色沉浸**
- 类比产品：剪映专业版 × Runway Gen-3 工作台 × Figma（多面板布局）
- 暗色主题为主（视频/图像工作流行业惯例），点缀**电影放映机的暖金色光**作为品牌强调色

## 1. 设计系统 (Design System)

### 1.1 色彩规范（暗色主题）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg-base` | `#0E0F13` | 最底层背景 |
| `--bg-surface` | `#16181F` | 面板/卡片背景 |
| `--bg-elevated` | `#1E2129` | 弹窗、下拉、悬浮层 |
| `--border-subtle` | `#2A2E38` | 分隔线、描边 |
| `--text-primary` | `#F2F3F5` | 主文字 |
| `--text-secondary` | `#9BA1AC` | 次要文字 |
| `--text-tertiary` | `#5C6370` | 占位/禁用 |
| `--accent` | `#F5B942` | 品牌金（主按钮、高亮、进度） |
| `--accent-hover` | `#FFCB5E` | 品牌金 hover |
| `--accent-gradient` | `linear-gradient(135deg, #F5B942 → #E8734A)` | 品牌渐变（Logo、主 CTA） |
| `--purple` | `#8B7CF6` | AI 生成相关标识（AI 能力统一紫） |
| `--success` | `#4ADE80` | 生成完成 |
| `--warning` | `#FBBD23` | 生成中 |
| `--error` | `#F87171` | 失败/错误 |
| `--info` | `#60A5FA` | 提示信息 |

**语义色用法约定**：
- **金色** = 用户主动操作（生成、导出、确认）
- **紫色** = 一切 AI 自动生成的能力入口（带 ✨ 图标）
- 生成状态徽标：`排队中`(灰) → `生成中`(金+动效) → `完成`(绿) → `失败`(红)

### 1.2 字体

| 用途 | 字体 | 字号/行高 |
|---|---|---|
| 品牌标题 | "Playfair Display" 或思源宋体 | 24–32px（电影片头感） |
| 界面正文 | "Inter" / "PingFang SC" | 14px / 1.5 |
| 界面次要 | 同上 | 12px |
| 代码/Prompt | "JetBrains Mono" | 13px |
| 大数字/时长 | "Inter" SemiBold | 20px, tabular-nums |

### 1.3 圆角 / 阴影 / 间距

- 圆角：卡片 `12px`，按钮 `8px`，输入框 `8px`，分镜卡 `10px`，头像/缩略图 `8px`
- 间距基准：`4px` 网格；面板内边距 `16px`；面板间距 `12px`
- 阴影：悬浮层 `0 8px 24px rgba(0,0,0,.45)`
- 毛玻璃：顶栏 `backdrop-filter: blur(12px)` + `rgba(14,15,19,.8)`

### 1.4 图标

- 图标库：Lucide（线性风格，1.5px 描边）
- AI 功能图标统一加 ✨ 前缀或使用紫色渐变光晕
- 常用图标：`Clapperboard`(项目)、`Sparkles`(AI)、`Camera`(机位)、`Move3d`(摆位)、`Film`(分镜)、`Play`、`Download`、`Settings`

## 3. 页面详细规格

### 页面 1：首页 / 项目列表

**布局**：顶栏 + 内容区

- **顶栏（高 56px）**：左侧 Logo「🎬 CineAI Studio」（金色渐变文字），右侧「+ 新建项目」金色主按钮
- **Hero 区（首次使用显示，可关闭）**：
  - 大标题（宋体 40px）：`一句话，一部短剧`
  - 副标题：`AI 剧本 · 分镜画面 · 视频生成 · 3D 导演台，一站式完成`
  - 居中大输入框（高 56px，圆角 12px，内含紫色 ✨ 发光边框）+「开始创作」金色渐变按钮
  - 输入框 placeholder：`例如：末世废土中，一个快递机器人学会了说谎…`
- **项目列表区**：
  - 标题「我的项目」+ 视图切换（网格/列表）
  - **项目卡片**（网格布局，每行 4 列，最小宽 280px）：
    - 16:9 封面图（取项目首镜画面，无则显示深色渐变 + 胶片图标）
    - 封面左下角状态徽标：`剪辑中` / `已导出` / `草稿`
    - 卡片下方：项目名（16px SemiBold）、`更新于 2 小时前 · 12 个分镜 · 01:24`（12px 次要色）
    - hover：卡片上浮 2px + 边框变 `--accent` + 显示「⋮」更多菜单（重命名/复制/删除）
- **空状态**：居中胶片插图 + `还没有作品，输入创意开始你的第一部短剧` + CTA

### 页面 2：新建项目 · 创意输入（向导，3 步）

**形式**：居中卡片式向导（宽 680px），顶部步骤条 `1 创意 → 2 风格 → 3 角色`

**Step 1 — 创意输入**：
- 标题：`描述你的故事`
- 大号多行文本域（高 160px），placeholder 示例 2~3 条可点击「换个灵感 🎲」随机填充
- 可折叠「高级选项」：
  - 时长滑块：30s ~ 3min（默认 60s）
  - 分镜数量：自动 / 8 / 12 / 16
  - 画幅：竖屏 9:16（默认）/ 横屏 16:9
- 底部：`← 取消` / `生成剧本 ✨`（紫色渐变主按钮，点击后进入生成动画）

**生成中状态（重要，需专门设计）**：
- 卡片切换为**剧本生成动画**：中央胶片图标 + 环形进度 + 逐条打字机式显示生成阶段文案：
  - `正在构思故事梗概…`
  - `正在设计角色…`
  - `正在拆分分镜（第 3/12 镜）…`
  - `正在匹配镜头语言…`
- 完成后自动跳入工作台

**Step 2 — 风格选择**：
- 标题：`选择画面风格`（此风格将锁定全片）
- 风格卡片网格（每行 3 列），每张含示例缩略图 + 名称：
  `电影写实` `国风古韵` `赛博朋克` `日式动漫` `3D 卡通渲染` `水墨黑白`
- 选中态：金色描边 + 右上角 ✓
- 底部单选组「画面比例」：9:16 / 16:9 / 1:1

**Step 3 — 角色确认**：
- AI 已根据创意预生成角色卡列表（横向卡片流）
- **角色卡**（宽 220px）：
  - 顶部 3:4 角色形象图（AI 生成占位）
  - 姓名 + 一句话人设（`林夏 · 26 岁末世信使，冷静寡言`）
  - 标签：`主角` / `配角`
  - 操作：`编辑` `换形象 🎲` `删除`
- 底部：`+ 添加角色`（虚线框卡片）
- 每张卡右下「音色试听 ▶」（TTS 预览）

### 页面 3：工作台主界面 ★ 核心页面

**整体结构**（1920×1080 设计基准）：

├────────────┬─────────────────────────────────┬───────────────┤
│            │                                 │               │
│  左侧面板   │        中央主编辑区              │   右侧面板     │

- 左右面板均可折叠（边缘有 `«` `»` 折叠把手），折叠后中央区最大化
- 三级导航：顶栏 Tab 切换主视图，左面板内容随视图联动

#### 3a. 分镜剧本视图

**中央区 — 分镜卡片网格（可切换横向时间轴流）**：

- 每行 3~4 张**分镜卡**（最小宽 300px），卡片结构（从上到下）：
  1. **16:9 画面区**：
     - 已生成：显示首帧图；hover 显示「▶ 预览视频」（视频内嵌播放）
     - 未生成：深色占位 + 灰色胶片图标 + `等待生成`
     - 生成中：缩略图 + 底部金色进度条 + 微光扫过动效（shimmer）
     - 失败：红色蒙层 + `重试 ↻` 按钮
  2. **镜号徽标**（左上角悬浮，金色圆形 `01`）+ 右上角状态点
  3. **元信息行**：`【中景 · 缓推】 5s`（景别与运镜用小标签样式 pill）
  4. **画面描述**（2 行截断，12px，点击展开编辑）
  5. **台词区**（若有）：引号样式 `「你确定要回去吗？」` + 小喇叭试听图标
  6. **卡片操作栏**（hover 显示）：`编辑` `重生图片 🎲` `生视频` `复制` `删除`
- 卡片拖拽排序（拖起时倾斜 3° + 阴影加深，目标位显示金色插入线）
- 卡片间「+」插入按钮（虚线圆）
- 顶部工具条：`添加分镜` `批量生图 ✨` `批量生视频 ✨`（批量按钮紫色）+ 视图切换

**左面板 — 剧本信息**（Tab: 大纲 / 角色）：
- 大纲 Tab：故事梗概（可编辑文本域）、主题标签、`重新生成剧本 ✨` 按钮
- 角色 Tab：竖排小角色卡（头像 + 名字），点击打开角色编辑抽屉

**右面板 — 分镜详情编辑器**（点选某张分镜卡后联动）：
- 分组表单：
  - **镜头语言**：景别（远/全/中/近/特写 单选 pill）、运镜（固定/推/拉/摇/移/跟 下拉）、时长滑块（3~10s）
  - **画面 Prompt**：多行文本 + `AI 优化 ✨` 小按钮 + 字数统计
  - **台词 / 旁白**：文本域 + 音色选择（下拉，带 ▶ 试听）
  - **导演台数据**：若已摆位显示 `📍 已设置场景与走位 · 查看`，否则 `去导演台摆位 →` 链接
  - **资产**：首帧图 / 视频的重新生成按钮 + 生成参数（种子、模型档位）

#### 3b. 3D 导演台视图 ★ 差异化界面

**中央区 — 3D 视口**（占满，深色画布 `#111318`）：

- 视口内元素：
  - 地面网格（GridHelper，深灰线）
  - **场景模板占位体**：家具/建筑用半透明灰盒（wireframe + 微填充）
  - **人物代理**：胶囊体 + 头部球 + 朝向箭头，主角用品牌色，配角用蓝/紫区分；头顶浮签显示角色名
  - **虚拟摄像机**：线框取景锥体（金色），可拖动
  - 人物/相机运动轨迹：地面上的**发光虚线曲线** + 关键帧节点（小圆点，选中放大）
- 视口右上角悬浮工具组（竖排毛玻璃按钮）：
  - `选择` `移动` `旋转` `缩放`（当前模式高亮）
  - `+ 添加人物` `+ 添加道具` `机位` `预演 ▶`
- 视口左下角：当前机位**子视口预览**（小窗 240×135，圆角，显示该机位渲染画面，可放大）
- 视口底部中央：`播放 ▶ / 暂停 ⏸` + 时间码 `00:04.2 / 00:08.0`
- 视口右上角主位：`应用到分镜 ✓`（金色按钮，确认后 directorData 写回当前分镜）

**左面板 — 场景资产库**：
- Tab：`场景模板` / `道具` / `人物`
- 场景模板列表（缩略图 + 名称）：`空房间` `街道` `办公室` `天台` `废墟` `森林`
- 道具：床、桌、椅、门、灯柱…（图标网格，点击/拖入视口）
- 人物：从项目角色卡引入

**右面板 — 属性检查器**（随选中对象联动）：
- 选中人物：名称、当前动作下拉（站立/走/跑/坐/倒下）、速度滑块
- 选中关键帧：时间输入、坐标、插值方式（线性/缓入缓出）
- 选中相机：FOV 滑块、焦段预设（24/35/50/85mm）、运镜描述（`AI 描述此运镜 ✨` 自动生成运镜文案，显示为紫色文本，如"镜头随人物向左横移并缓慢推近"）

**底部（此视图下时间轴区替换为关键帧时间轴）**：
- 高度 140px，多轨道：`相机轨` + 每个角色一轨（轨道名 + 色点与视口人物同色）
- 轨道上关键帧为菱形节点，可拖动改时间
- 空白处双击 = 在当前时间插入关键帧
- 左侧轨道头：角色名 + 显隐 👁 + 独奏 🔊式隔离按钮

#### 3c. 渲染队列视图

- 中央区为**任务列表表格**（行高 72px）：

| 分镜缩略图 | 镜号 | 任务类型（生图/生视频/配音/合成，pill 标签） | 状态 | 进度条 | 耗时 | 操作 |
|---|---|---|---|---|---|---|
| ▣ 缩略图 | 03 | `视频` | 🟡 生成中 | ▓▓▓░░ 60% | 01:24 | 取消 |
| ▣ | 05 | `图片` | 🟢 完成 | — | 00:38 | 查看 |
| ▣ | 07 | `视频` | 🔴 失败 | — | — | 重试 · 详情 |

- 顶部汇总条：`待生成 3 · 生成中 2 · 已完成 9 · 失败 1` + `全部重试失败项` + `暂停队列` / `继续队列`
- 每行展开后显示：API 供应商（可灵/即梦）、任务 ID、日志（mono 字体）、成本估算 `≈ ¥1.2`
- 空状态：`所有分镜已就绪，去导出成片吧 →`

**底部时间轴（分镜/队列视图共享）**：
- 横向排列全部分镜**视频缩略条**（宽度按时长等比），颜色条带表示状态（绿=就绪/金=生成中/灰=待办/红=失败）
- 选中分镜高亮金色描边，与中央区卡片双向联动
- 左端：`▶ 全片预览`（连续播放所有就绪片段）+ 总时长 `01:24`

### 页面 4：导出预览页

**布局**：左右结构

- **左侧（约 60%）— 播放器**：
  - 9:16 竖屏播放器居中（或按项目画幅），深色留黑边
  - 底部自定义控制条：进度条（金色）、播放/暂停、音量、字幕开关 CC、倍速
  - 播放器上方显示 `合成预览 · 1080×1920 · 24fps`
  - **合成中状态**：播放器区显示环形进度 + 阶段文案（`生成配音 → 拼接分镜 → 烧录字幕 → 混音`，当前阶段金色高亮）
- **右侧 — 导出设置面板**：
  - 分辨率：720p / 1080p / 2K（radio 卡片）
  - 帧率：24 / 30
  - 格式：MP4 / WebM
  - 开关组：`硬字幕` `背景音乐` `片头片尾` `水印`
  - BGM 选择：曲风卡片（悬疑/温情/热血/轻快），带 ▶ 试听
  - 底部固定：成本预估 `本次导出预计消耗 ¥X.X` + `导出成片` 金色渐变大按钮（60px 高）
- **导出完成后**：播放器播放成片，右侧变为 `下载 MP4` `导出封面图` `分享链接（复制）`

## 4. 全局组件规格

| 组件 | 规格 |

| Tooltip | 深色气泡，8px 圆角，延迟 300ms |

## 5. 关键交互流程

1. **生成剧本**：输入创意 → 生成动画（阶段文案打字机效果）→ 自动进入工作台，分镜卡呈骨架屏逐张点亮
2. **单镜生成**：点分镜卡「生图片」→ 卡片变生成中（shimmer）→ 完成后缩略图淡入 + 绿色状态点 + Toast
3. **图 → 视频链**：首帧图就绪后，「生视频」可用；生成中右下角浮出迷你任务球（可收起为角标）
4. **导演台摆位**：分镜卡 →「去导演台」→ 切换 3b 视图并高亮当前镜 → 摆位/走位/机位 → `应用到分镜 ✓` → 回到分镜视图，卡片出现 📍 徽标，运镜 pill 自动更新
5. **全片预览**：时间轴 `▶` → 底部时间轴变播放态（金色播放头扫过），逐段播放在底部弹出的预览条中
6. **导出**：队列全绿 → 顶栏「导出」高亮呼吸动效 → 导出页合成动画 → 完成页

## 6. 动效规范

- 全局过渡：`150ms ease-out`（hover/按钮）
- 面板折叠/抽屉：`250ms cubic-bezier(.4,0,.2,1)`
- AI 生成 shimmer：2s 循环扫光
- 步骤条/进度：金色填充，进度变化带 `300ms` 缓动
- 播放头：实时拖动，关键帧吸附（视觉上播放头经过关键帧时短暂放大脉冲）
- 空状态插画：轻浮动循环动画（上下 6px，4s）
