# CineAI Studio v2 Stitch 屏幕提示词包

本文件是可直接粘贴进 Google Stitch 网页版的提示词集合。一次生成一个屏幕，
按第五章的顺序执行。设计契约见 `DESIGN-v2.md`，操作流程见 `STITCH-RUNBOOK.md`。

## 一、使用方法

Stitch 对"一个提示词 = 一个屏幕"的效果最好。每条屏幕提示词都由两部分拼成：

```text
[通用前缀]  +  [该屏幕的专属段落]
```

先把第二章的通用前缀原样粘贴，紧接其后粘贴目标屏幕的专属段落，再发送。
不要在一个提示词里同时要求两个页面。

## 二、通用前缀（每条必带）

```text
为桌面端设计一个界面，画布 1440×1000，同时说明在 1920 宽下的自适应行为。
这是专业影视剪辑工作台，暗色、密集、克制，不是消费级应用。

视觉约束：
- 背景 #0E0F13，面板 #16181F，浮层 #1E2129，结构描边 #2A2E38。
- 主文字 #F2F3F5，次要文字 #9298A5。
- 金色 #F5B942 只用于用户主动操作（主按钮、当前选中项、时间轴游标）。
- 紫色 #A293EE 只用于会触发 AI 模型调用的入口。
- 完成绿 #75C9A1，失败红 #EF8385。
- 圆角：输入框与徽标 6px，按钮 8px，卡片与面板 12px，弹窗 16px。

排版约束（重要）：
- 正文基准 14px / 行高 22px。面板内次要说明 13px。
- 表单标签、表头、状态文字 12px。徽标与计数 11px，这是绝对下限。
- 禁止出现任何小于 11px 的文字，禁止 8px、9px、10px 字号。
- 数字、时间码、时长使用等宽字体并右对齐。
- 中文使用系统字体（苹方 / 微软雅黑），不要为中文指定西文字体。

禁止事项：
- 禁止 Material Symbols 图标字体，禁止 emoji 作为图标。使用 24×24 网格的描边风格图标。
- 禁止玻璃拟态、霓虹光晕、渐变背景、大面积金色填充、胶囊化大圆角。
- 禁止 lorem ipsum 与英文占位文案，所有文字使用中文。
- 不要画出产品不具备的功能（见下）。

产品边界，不要画对应的可操作控件：
- 没有口型同步功能。
- 没有分集 / 多集结构，只有单条短片。
- 时间轴不支持转场库、多轨编辑、变速，只有首尾淡化。
- 没有自动视觉一致性审核。
```

## 三、术语纪律（追加到每条提示词末尾）

```text
界面上不得出现以下工程词汇，它们只能出现在默认折叠的「技术详情」区域里：
task_id、source_task_id、providerTaskId、parent_revision、expected、nonce、
entityId、version、stale、asset_id、voice_id、日志 JSON，
以及任何供应商或模型名称（如 MiniMax、H3、mimo-v2.5-tts-voiceclone）。

改写规则：
- "并发上限 2" → "同时最多生成 2 个镜头"
- "stale / 已过期" → "素材已过期，需重新生成"
- "降级原因" → "部分参考图未生效，已用文字描述补足"
- 金额统一使用人民币，如 "预计 ¥3.60，实际以服务商结算为准"。
  全界面只允许一种价值单位，不要出现"积分"。
- 状态一律用图标 + 文字同时表达，不允许只用颜色区分。
```

## 四、生成顺序

顺序不是随意的：先做最密集的工作台屏幕，它确定整套面板、卡片、状态与密度语言；
后续屏幕复用同一套语言。

| 序号 | 屏幕 | 为什么在这个位置 |
| --- | --- | --- |
| 1 | 分镜创作（`/studio` 阶段 04） | 全产品最密集的屏幕，先定密度与卡片语言 |
| 2 | 工作台外壳（阶段导航 + 头部 + 底部动作条） | 五个阶段共用，第 1 步已顺带产出，此处收敛 |
| 3 | 故事方案（阶段 01） | 双栏文稿布局 |
| 4 | 角色形象与声音（阶段 02） | 信息量最大的编辑页 |
| 5 | 环境素材（阶段 03） | 单列长页，检验第 4 步的卡片语言 |
| 6 | 预览与导出阶段（阶段 05） | 就绪度汇总 |
| 7 | 首页（`/`） | 入口页，需要独立气质 |
| 8 | 新建项目（`/new`） | 单表单极简页 |
| 9 | 生成任务（`/queue`） | 表格与队列 |
| 10 | 预览与导出（`/export`） | 最长页，双列 |
| 11 | 3D 导演台（`/director`） | 视口 + 三栏 |
| 12 | 本片角色（`/characters`） | 卡片网格 + 编辑态 |

### 屏幕 1 · 分镜创作（`/studio` 阶段 04）——锚点屏

**这一屏当前最严重的问题：** 分镜卡片在约 430px 宽内同时塞入序号、时长、

```text
  01 故事方案 / 02 角色形象与声音 / 03 环境素材 / 04 分镜创作 / 05 预览与导出。
  当前项用金色下边框和金色编号，不要用背景填充。每项下方用 11px 显示状态，

- 就绪点必须三个维度分别可见，不要合并成一个总状态。
- 画板顶部一行状态提示：「分镜已确认，按需生成画面与声音」，右侧「点击卡片编辑」。

  → 折叠的「其他画面操作」「其他声音操作」两个次要入口
  → 折叠的「技术详情」。
- 生成操作按画面和声音两组呈现，每组一个主按钮：
  画面组主按钮「生成画面」，声音组主按钮「生成配音」。
  次要操作（重新抽取画面、生成结束状态尾帧、重录本镜全部配音）收进可展开的次要区，
  不要和主按钮平铺在同一行。

左栏大纲（210px）：
- 「STORY OVERVIEW」小标题 + 故事梗概（13px，最多 7 行截断）
  + 三个 11px 徽标「电影写实」「9:16」「5 个镜头」+ 文字链接「查看与编辑故事方案」。
- 分隔线下方「SCENE LIST」+ 场次列表，每项编号 + 标题 + 一行「中景 · 6.2s」。

```
